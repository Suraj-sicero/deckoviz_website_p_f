# Deckoviz School Suite Documentation

## Overview
The **School Suite** is a vertical expansion of the Deckoviz ecosystem tailored for educational environments. It is a standalone React frontend (built with Vite) that provides a suite of tools for students and educators, heavily leveraging the Vizzy AI system for tutoring, creative guidance, and progress tracking.

## 1. Feature List & Pages

The application is structured around several core modules, all accessible via the main application shell sidebar.

*   **Home (School Ground):** The main dashboard displaying an overview of the user's day, upcoming classes, and quick actions.
*   **Vizzy Chat (`/vizzy`):** The core generative AI interface where users can chat with Vizzy, generate images/visualizations, and get help.
*   **Daily Journal (`/journal`):** A space for students to reflect, with AI-driven prompts and insights.
*   **Progress Tracking (`/progress`):** Analytics and data visualization of a student's performance, skill acquisition, and time spent.
*   **Creative Studio (`/creative`):** A dedicated area for generating and managing creative assets and artwork.
*   **Collections (`/collections`):** Management of visual collections (playlists) to be displayed on the Deckoviz frame.
*   **Classes & Curriculum (`/classes`, `/curriculum`):** Academic management showing schedules, coursework, and syllabi.
*   **Classroom (`/classroom`):** The active learning environment for a specific subject.
*   **Group Sessions (`/group`):** Collaborative spaces for team projects or study groups.
*   **Evaluation (`/evaluation`):** Assessment and grading interfaces.
*   **Tool Library (`/tools`):** A repository of educational tools and interactive widgets.
*   **Admin & Business (`/admin`, `/business`):** High-level dashboards for school administrators to manage users, hardware, and analytics.

## 2. Repository Structure

The codebase is organized in a standard modern React pattern within the `src/` directory:

*   `/assets`: Static assets, images, and global styles.
*   `/components`: Reusable UI elements.
    *   `/layout`: Contains the `AppShell.tsx` which defines the sidebar navigation and main content area.
    *   `/ui`: Generic UI components (buttons, inputs, cards).
    *   `/home`: Components specific to the dashboard.
*   `/data`: Mock data or static configuration files (e.g., `lifeSkills.ts`, `tools.ts`).
*   `/pages`: The core views of the application. Each `.tsx` file here corresponds to a major feature/route and typically has a companion `.module.css` file for styling.
*   `/store`: State management.
*   `/styles`: Global CSS files (`global.css`).

## 3. State Management & APIs

### State (Zustand)
The application utilizes **Zustand** for lightweight, centralized state management. 
*   **`useAppStore.ts`**: The primary store managing global application state (e.g., current user context, theme preferences, global notifications).

### Routing
Routing is handled by `react-router-dom` in `App.tsx`. All routes are nested under the `<AppShell />` layout component to ensure consistent navigation across the application.

## 4. UI / UX Design System

The application adheres to a "Premium Design" aesthetic, moving away from basic UI frameworks to a highly customized look and feel.

*   **Styling Strategy:** Vanilla CSS Modules (`.module.css`). This provides scoping and prevents style conflicts without the overhead of heavy CSS-in-JS libraries.
*   **Animations:** `framer-motion` is used extensively for micro-interactions, page transitions, and dynamic layout changes, making the interface feel "alive".
*   **Iconography:** `lucide-react` is used for consistent, modern vector icons across all interfaces.
*   **Visual Language:** The design relies on soft drop-shadows, rounded card interfaces, and subtle purple/blue gradient accents to create a welcoming, futuristic educational environment.
